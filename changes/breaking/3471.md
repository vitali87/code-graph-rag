A repository's `.cgr.md` no longer reaches the agent's system prompt until you approve its content. `cgr start` and `cgr optimize` show the file and ask (the default is no), and remember the approval until the file changes. `cgr start -a` and the MCP server's `ask_agent` cannot ask, so they skip a `.cgr.md` you have not approved and log why. Your own `~/.cgr.md` loads as before.

To keep the old behaviour, approve each repository's file once in `cgr start`, or set `CGR_TRUST_PROJECT_INSTRUCTIONS=true` to load every repository's file without asking. Use the variable only for repositories you control, such as CI on your own code.

Existing installs: nothing is approved yet, so the first `cgr start` in each repository with a `.cgr.md` asks once. Until then, non-interactive runs work without the file. See [Project instructions](https://docs.code-graph-rag.com/architecture/security/#project-instructions).
